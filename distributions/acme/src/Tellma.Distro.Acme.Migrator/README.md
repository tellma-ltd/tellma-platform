# Tellma.Distro.Acme.Migrator

Acme's migrator: the console host that creates and migrates the catalog, the identity engine's
`idsvr` schema and every tenant database, and that registers, provisions and changes the state of
tenants. `Program.cs` is one call to `TellmaMigrator.RunAsync` with Acme's slug, its composition and
the identity store's migrations.

```bash
dotnet run --project distributions/acme/src/Tellma.Distro.Acme.Migrator -- migrate
dotnet run --project distributions/acme/src/Tellma.Distro.Acme.Migrator -- provision --name "Acme 2"
dotnet run --project distributions/acme/src/Tellma.Distro.Acme.Migrator -- status
dotnet run --project distributions/acme/src/Tellma.Distro.Acme.Migrator -- emit-client-assets <dir>
```

The project links the web host's `appsettings.json` and `appsettings.Development.json`, so both hosts
read one configuration; its launch profile runs in Development.

| Path | Holds |
|---|---|
| `AcmeDesignTimeFactory.cs` | The design-time factory `dotnet ef` builds the tenant model with: Acme's slug and composition, no database. |
| `Migrations/Tenant/` and the snapshot under `Tellma/Distro/Acme/Migrator/Migrations/Tenant/` | The tenant database's migrations, generated by `dotnet ef` and never edited by hand. The distribution's README gives the command. |
