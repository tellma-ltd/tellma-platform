# PC-156: Bell, tray, panels and tm-assignment-list

## Implementer notes

### What was built

Spec 0028 §6 (all), §7.1–§7.4 and the §13 page-context and dump rows, in
`client/projects/core/tellma-core/attention/` (eager `@tellma/core/attention` and a new lazy chunk of
it) and the new shared entry point `client/projects/core/tellma-core/attention-rows/`.

- **`@tellma/core/attention-rows`** (new, shared: loads with whichever code imports it; graph entry
  `'./attention-rows': { load: 'shared', imports: ['.'] }` in `tellma-core-tools`' entry-point map).
  - `TmAttentionText` and `tmIcuArguments` moved here from `/attention` (git mv, D-257's carry), so
    the eager `/attention` graph no longer holds the server-text code; the arrival toasts' chunk and
    the panels' chunk import it.
  - `tm.attentionRows` strings (`src/tm-attention-rows-strings.ts`): the caption title
    (`tm.attention.assignment.title` moved to `tm.attentionRows.assignment.title`), the list's lines,
    "New", the loading label and the separator.
  - `TmAssignmentList` (`tm-assignment-list`, `src/tm-assignment-list.ts`): `items`, `related`,
    `party`, `variant`, `seenAt`, `loading`, `fallback`, `label`; output `activated { row, position }`.
    Tray rows: entity label + code (code in `<bdi>`), line 2 = comment / "Returned by" / detail ·
    amount / "Assigned by" / "Assigned automatically"; by-me rows "With {assignee}". Home rows: the
    code alone, line 2 = detail else the comment, the amount at the end. New marks: to-me,
    `assignedAt > seenAt`, not self-assigned. Three skeleton rows while `loading`. Row views are cached
    per row object (remade when variant/party change); names via `TmDisplayNames` from `related`; a
    minute ticker keeps the link names' relative times current. Rows are real links
    (`TmUrls.target`), a plain click navigates in-app and emits `activated`.
  - `ɵTmRovingRows` (`src/tm-roving-rows.ts`): one tab stop per list, Up/Down/Home/End between rows,
    Left/Right (direction-mapped) among a row's controls, Delete → `rowDelete`, focus kept on the row
    in the leaving row's place, else the previous, else `fallback` (the heading).
- **Buttons** (`attention/src/tm-attention-buttons.ts`, eager, exported): one component,
  `TmAttentionButton`, under both `tm-bell-button` (lucide `bell`, ring while `jobsRunning > 0`) and
  `tm-tray-button` (`inbox`), its panel read from its element's name (spec 0028 §1 names two classes,
  `TmBellButton` and `TmTrayButton`; one class keeps one compiled template and stylesheet on the first

  `aria-expanded`, `aria-controls` while open, `aria-keyshortcuts`; shortcuts
  `tm.attention.notifications` (Alt+Shift+U) and `tm.attention.assignments` (Alt+Shift+Q) through
  `TmShortcuts` (inFields, not over modals). Each button creates its own panel host from the chunk on
  pointerenter, focus, press, or the first idle moment; a failed load reports telemetry and retries on
  the next intent.
- **Panels' chunk** (`tm-attention-panels`, `attention/src/tm-attention-panels.ts`, loaded with

  - `TmAttentionPanelHost`: a `tm-popover size="md" align="end"` from lg (max block size

    titled with the panel's heading (`TM_MODAL_DATA.drawer` hides the in-panel h2). It follows
    `TmAttention.open()`; a popover/drawer close closes the model.
  - `TmBellPanel` (`src/tm-bell-panel.ts`): header (h2, Mark all as read while unread > 0, More

    (severity icon, real link to `notifications/{id}/open`, Download for `core.export.ready`, narrow

  - `TmTrayPanel` (`src/tm-tray-panel.ts`): h2 with an inline counter ("{n} open" for AT), the tray

  - `TmAttentionDump`: the support dump's `attention` section (open panel, badges, shown banners).
  - `tm.attentionPanels` strings (`src/tm-attention-panels-strings.ts`).
- **App bar** (`shell/src/app-bar/tm-app-bar.ts`): the reserved bell/tray spans are replaced by
  `<tm-bell-button data-tm-slot="bell" />` and `<tm-tray-button data-tm-slot="tray" />`.

### Deviations

See the commit message's Deviations list; the non-obvious ones are repeated under "Examine hardest".

### Open risks

- The assignments document is still unregistered (PC-207), so the tray shows skeletons until a copy
  exists, and the footer link is hidden while the server routes no `core.Assignment`.
- The dump section registers when the panels' chunk loads (at idle after the first frame), not with the
  eager model; a dump taken before that idle moment has no `attention` section.

### Examine hardest

- The `TmPopover` change (`tellma-core-ui/popover/tm-popover.ts`): `modalsBelow` is captured when the
  popover opens; any modal opened later is "above". Check nested popovers and a popover opened from
  inside a modal.
- Stop: the panel's button confirms only for `commitsInSteps` handlers (spec §6.2), while the page
  action `attention.stop-job` is declared destructive with a confirm, so the dispatcher always asks;
  the panel calls the model directly rather than invoking its own page action (spec 0026 §9.5).
- The bell's arrival hold (`#shown`/`#atTop`) and the focus recovery when a focused row is withdrawn.
- The size split: what stays eager in `/attention` versus the panels' chunk, and the new ceilings.
