- A6.5-1e — §Frontend → App framework — the PWA and service-worker decision: generated worker config, one prefetched `shell` group, on demand only the ECharts engine chunk, the studio and the support tools (C-0034-5); no API caching; Chromium's installability check nightly; updates by banner, and `412 client-outdated` with a reload that keeps unsaved edits — needed by spec 0024
- A6.5-1f — §Frontend → App framework, §Glossary "Warm launch" — the 7-day warm launch stated as the session's idle window, 7 days by default (Q-34): the worker cache plus one IndexedDB transaction before chrome, the first network call is the page's data, a session that ends takes the stored data with it, sign-out reaches every tab — needed by specs 0024, 0025
- A6.5-1g — §Frontend → App framework — one hub connection per browser per tenant (leader tab, failover); reads cancellable and writes not, `traceparent` on every call; the SPA hosting rules (immutable hashed files, `no-cache` `index.html`, CSP with Trusted Types, navigation-only fallback); one page-context registry and action model; a closing paragraph links specs 0027–0035 by the pages they own — needed by specs 0024–0035
- A6.5-1h — §Frontend → UI component library, "Accessibility & i18n" — the stale `TmDateAdapter`/`TmNumberAdapter`/`TmCurrencyAdapter` sentence ("a Hijri calendar provided by a Locale pack") becomes `TmL10n` with `TM_ACTIVE_LOCALE` and `TM_CALENDAR`: Gregorian built in, `calendar-umalqura` and `calendar-ethiopic` entry points loaded by the tenant's calendar codes, calendars never a Locale pack's — needed by spec 0024
