# Tellma.Core.Tests

Unit tests for `Tellma.Core`. No database, no network: compositions run against in-memory
configuration, the startup gate runs under a real generic host, and the file-system blob store runs
in a fresh temporary directory per case.

A distribution extending all four access entities (`AccessLeafTests`): every configuration closed over its leaf, every foreign key reaching the leaf, the defaults' names and seeds kept, and the startup gate passing.
