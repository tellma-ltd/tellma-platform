# Tellma.Core.AspNetCore.Tests

Tests for `Tellma.Core.AspNetCore`, the web host. No database, no network: each host is a real
`WebApplication` on a test server, composed with the real `AddTellma`, `UseTellma` and `MapTellma`,
over an in-memory tenant catalog and session table, a fake clock, a scripted user connection, a
static identity server (a fixed issuer and signing key, so no discovery document is fetched, and a
fake back channel answering the pushed authorization and token requests) and probe endpoints on
every surface that answer the request context they ran under. The in-proc identity mode runs over
the real engine, its database-bound background services removed.

| Folder | Covers |
|---|---|
| `Tenancy/` | The tenant verdict matrix: every tenant state against reads, writes and writes a read-only tenant allows, for an anonymous caller, a member and a stranger, on the web surface, the hub's front door, a blob read and a public API read and write (a service account's token included); the principal, session, client and assurance a session binds; a stale catalog answering `503 catalog-unavailable` with `Retry-After`; a tenant segment the route admits but that is not digits alone (`+1`, `1 `, ` 1`) answering `404 tenant-not-found` with no error logged; the guard reaching an endpoint from a data source that ignores endpoint filters, and running once on a route handler that both the filter and the backstop wrap. |
| `Csrf/` | Every CSRF rule on a cookie-authenticated write (`Sec-Fetch-Site`, `Origin` and `Referer`, `Tellma-Client`, the JSON media type and the binary opt-in); the provenance rules alone on safe methods and the hub's negotiate; the tenantless session fallback; bearer and anonymous endpoints exempt; the refusal counter by rule. |
| `Authentication/` | Scheme isolation (a token never authenticates a cookie surface, a cookie never a bearer surface, the control plane its own scope); the public API's scope and audience; MCP's per-tenant audience and client name; a token of another type refused; how a bearer token's claims name a user, a service account or nobody; the step-up challenge's header, problem and counter, and a service account refused an endpoint with an assurance bar. |
| `Routing/` | The endpoint audit: the platform's endpoints and the probes pass it, and each violation a distribution could map fails startup naming its method and route, at `MapTellma` or when the host starts (a tenant endpoint off the groups, a surface stamped on another surface's group, an MCP endpoint its front door did not install, a delegate the guard does not wrap, an endpoint that does not state whether it mutates, a stack's reserved resource segment, a plain endpoint or a stated mutation on the Hub group, short-circuiting without anonymous access, a policy that names no scheme); a real hub on the Hub group stamped a read; an anonymous tenantless endpoint allowed to short-circuit; `WithMutation` clearing a read-only allowance; `MapTellma` mapping every route and group, refusing a pipeline `UseTellma` did not install, and mapping once. |
| `Surfaces/` | The distribution info document (shape, cache header, links, the admin surface on and off); the protected-resource metadata, alike for every tenant id; liveness; the admin surface over an in-memory catalog (info and tenant counts, the version prefix, listing, registration with and without a provisioning trigger, malformed bodies, state changes and the states it refuses, the catalog's refusals, members of an unknown tenant, no CSRF headers needed); the SPA over a generated publish manifest shaped as a .NET 10 publish writes it (hashed and unhashed caching, the index page's security headers and policy on every route and Brotli or gzip variant of the shell, a deep link logged under its own path, the navigation and segment rules, `route-not-found` against `not-found`, a host without the SPA, the policy's realtime and identity origins). |
| `Bff/` | The sign-in: the pushed request (client credentials, PKCE, scopes, language, assurance and age), the distribution's login policy forwarded and never weakened by the query, the parameters it refuses, an identity token without a session or subject or with a malformed subject storing nothing, the principal trimmed to the kept claims, the ticket persisted with the cookie expiring with the row, the profile cookie, a sign-in over an existing session ending it; the landing over every row of the client's launch-landing vectors, a sign-in's own return address, a failed landing; the user document's shape and its 401; the local and global sign-outs (the listener told the handle, never the key, while the row still exists; `Clear-Site-Data`; the end-session address with the session's identity token as its hint; the local fallback, logged, when the metadata cannot be read or names no end-session endpoint), the CSRF control on the sign-out and an unknown scope; the back-channel logout's token vectors (issuer, audience, type, events, nonce, expiry, `iat`, signing key, subject), its sid, subject-only and replayed tokens, and its 503 when the metadata cannot be read. |
| `Sessions/` | The sliding renewal moving the row and both cookies to one expiry, none early in the window, none for background activity (the activity header, client telemetry, the hub); the token refresh (the redemption, the version, single flight under concurrent requests, the refreshed claims, tokens and profile cookie, a refused refresh, another subject or an identity token for another client ending the session, no refresh token, a malformed success and a stale signing key put off, a rolled key accepted after one re-read, the outage allowance and past it, the backoff after a deferral, the redemption's deadline, the absolute lifetime); the sweep and the membership reconciliation on a fake clock, the latter on the lock holder alone and past a failed tenant. |
| `Hosting/` | The persisted key ring outside Development, the framework's forwarded-headers switch refused, the identity check's secrets and in-proc mail, readiness following the catalog and naming no check; the in-proc engine's protocol endpoints, discovery and pages reached without a session, its forms left to its own antiforgery, its sign-in-only pages challenging with its own scheme whatever platform session is presented, its sign-in cookie refused by the platform's session surfaces, its sign-in code sent live through the real email pipeline outside any tenant while any other tenantless send still fails, and a missing engine told from one of another release. |
| `Observability/` | A browser's `traceparent` adopted without its sampling decision, `Tellma-Trace-Id` and `Tellma-Build` on every answer including early refusals, database spans stripped of query text, each log event reaching every logger provider once with none of the host's defaults left, and a tenant request's completion event naming its tenant, category, subject and user. |
| `Infrastructure/` | The test host, the probe endpoints and hub, the in-memory catalog write side, session rows, membership hints and reconciliation store, the fake identity server and the browser's half of a sign-in, a metadata manager a test scripts, a recording session listener, the problem reader and a capturing logger provider. |

```bash
dotnet test test/core/Tellma.Core.AspNetCore.Tests
```
