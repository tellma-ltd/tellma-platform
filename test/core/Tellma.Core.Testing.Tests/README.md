# Tellma.Core.Testing.Tests

Tests for the shipped test package, and for the piece of the shared test plumbing whose silence the
leak suites rely on. Untested test infrastructure produces false green everywhere downstream, which
is the whole reason this project exists.

| Folder | Covers |
|---|---|
| `Database/` | The collation pin passing a model in the platform collation whose initial migration carries an annotation-only database operation, and naming a model in no collation, a model ahead of its migrations, and a migration that changes the collation up or down. The latest-migration pin accepting the last migration and refusing a stale constant or an assembly without migrations. |
| `Email/` | The capturing sender's thread safety, its lifetime-ordinal scripting, its event-driven wait (including the timeout), and the fact that it rejects an invalid message like any other transport. Both `AddCapturingEmail` modes, with the transport mode proving the router and its sandbox marking stay in the loop. The delivery-event builder's determinism and its verbatim redelivery. |
| `Jobs/` | The job probe driving a sample handler: a fresh item marked for a retry with its error, an item resumed from a seeded checkpoint succeeding with its notification, a requested cancel stopping the handler and leaving the item unmarked, the reason escalation, and a checkpoint stored under the platform's rules and cleared. |
| `Sql/` | The shared database creation's retry policy: only SQL error 1807 (alone or with the 1802 that follows it) is transient, never 1802 alone, an existing database, a deadlock, a timeout or a non-SQL exception; the jittered doubling waits and their ceiling; the bound on runs, after which the last run's own exception surfaces; and a non-transient failure or a cancellation surfacing at once. The creation statement's bracketing, the refusal of a blank name or of a collation that is not a plain name (it is spliced unquoted), and the five-minute command bound every creation and preparation command carries. Against a real server (`Category=Integration`): a preparation's batches share one session; and, under a real held `model` lock on the assembly's own container (skipped when `TELLMA_TEST_SQL` names a shared server), SQL Server's own 1807 is classified as transient, a one-run policy surfaces it unchanged, and six concurrent creations each log a retry and all exist once the lock is released. The end-of-suite drops: the drop statement (single-user with the sessions rolled back, then the drop, only for a database that exists, the name bracketed and quoted); only a database held for a moment is transient (in use 3702, locked 5061, taken in single-user mode 5064 or 924, in transition 952, a deadlock 1205, alone or with the 5069 that follows), never the follow-up alone, a missing database, the `model` lock, a timeout or a non-SQL exception; the drop path through its seams (the command runner and the pool clearer), with SQL Server refusals built through SqlClient's own factories: a held refusal runs again after the pools are cleared and is logged, any other refusal (a missing database, a timeout) surfaces at once with no rerun and no clear, and every run carries its statement and the five-minute bound; a connection that cannot be opened leaves every database untried and named, its failure the inner exception; and the loop over the databases, which tries every one past a failure, stops once the connection is lost, names every database left behind with each failure as an inner exception, and lets a cancellation through at once. Against a real server: two databases, one with a session idle in the pool and one inside an open transaction, are dropped, the transaction rolled back, the pools cleared once before the first drop and every drop under the five-minute bound; and a database reserved but never created is passed over. The server tests share one collection, so the assembly starts one container and the `model` hold never overlaps a creation or a drop. |
| `Logging/` | The shared capturing logger provider's walk, which the suites that assert a secret reaches no log depend on: a value is found in a pair sequence whose message redacts it, in a non-generic dictionary's value and key, in a destructured object nested in a member, in an exception's data and in a scope; a cyclic state ends with the value behind the cycle still found; a throwing getter is skipped; and nothing is found where the value is absent. |

## Running

```bash
dotnet test test/core/Tellma.Core.Testing.Tests --filter "Category!=Integration"
dotnet test test/core/Tellma.Core.Testing.Tests --filter "Category=Integration"   # needs Docker
```

The contention test holds the `model` lock, so it runs only on a container the fixture starts and is
skipped when `TELLMA_TEST_SQL` names an existing server, which other suites may share.
